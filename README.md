<h1 align="center"> Conversor de Moedas </h1>

Challenge, Turma One G8 Oracle, Alura.

Descrição:
* Conversão de USD para BRL, ARS, EUR, GBP. Vice e versa;
* Função para exibir histórico de conversão no console;
* Função de log, todo histórico é jogado automaticamente para um arquivo txt;
* Função de listar o histórico mesmo saindo da aplicação, continua salvo.

Caso teste a aplicação, precisará da chave da api e o caminho exato do log.txt pra funcionar corretamente.
